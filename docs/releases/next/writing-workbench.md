### New

- Adds a development writing-workbench plugin with argument planning, manual
  provisional coverage, native rewrite review and portable JSON templates.
- Lets permissioned plugins request text through the configured Textus AI
  provider and cancel their own requests.

- Adds a local template workshop that turns selected text headings and checklist items into editable JSON plans or review rubrics. Rubric assessment offers a cost estimate and runs only on request, retaining results for the examined document version.
- Keeps paragraph notes beside native writing, with author decisions and reviewable rewrite alternatives. Original/revision comparisons preserve a read-only snapshot beside a separately saved working file.
