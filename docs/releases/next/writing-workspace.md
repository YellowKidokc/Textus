### New

- The sidebar and AI panel can show one, two or three columns. Drag their
  dividers or use the arrow keys to adjust widths; the layout is remembered.
- Use **Split document column** to open documents side by side, including
  three columns. The existing document dividers resize each pane.
- **Writing tools › Rearrange outline** hides and locks the body while you
  move headings together with their paragraphs and subsections. Choose the
  heading levels, drag sections or use the arrow buttons, then Apply or Cancel.
  Applying in the visual editor is one undo step.
- **Paragraph scores** evaluates a selected paragraph against up to 20 editable
  criteria using the configured AI provider. Each run is explicit and may cost
  money. Scores are AI estimates, not measured statistics or verified facts;
  an inapplicable criterion can return no score. Results disappear when the
  paragraph, criteria, provider or model changes. API keys stay in the existing
  provider settings.
